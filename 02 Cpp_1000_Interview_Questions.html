Batch 1: C++ Basics & Core Syntax (Q1–Q100)

Section A — Fundamentals & Syntax (Q1–Q25)

  1. What are the main features of C++ that differentiate it from C? Supports classes/objects, function overloading, templates, exception handling, and stronger type checking.

  2. Explain the difference between a compiler and a linker. Compiler translates source code to object code; linker combines object code into an executable.

  3. What is the purpose of the main() function in C++? It serves as the entry point for program execution.

  4. What is the difference between #include <filename> and #include "filename"? <> searches system directories, "" searches local directory first.

  5. Define the term “namespace” in C++. A declarative region that provides scope to identifiers to avoid name conflicts.

  6. What is the purpose of the using namespace std; directive? It allows direct access to the standard library without prefixing std::.

  7. What are the different types of C++ data types? Basic: int, char, float, double, bool; Derived: arrays, pointers, references; User-defined: class, struct, enum.

  8. How does C++ handle integer and floating-point division differently? Integer division truncates the decimal; floating-point division preserves it.

  9. What is type casting? Describe implicit and explicit casting. Converting one data type to another; implicit is automatic, explicit uses a cast operator.

  10. Explain the concept of a constant in C++. A value that cannot be altered after initialization.

  11. What are the different storage classes in C++? auto, register, static, extern, mutable.

  12. What is the difference between global and local variables? Global: accessible anywhere; Local: accessible only within the block they are defined.

  13. Define scope resolution operator (::) and its use. Accesses global variables or class members when names are hidden by local variables.

  14. What is the size of bool, char, int, float, and double typically? bool: 1 byte, char: 1 byte, int: 4 bytes, float: 4 bytes, double: 8 bytes (platform-dependent).

  15. What are lvalues and rvalues in C++? lvalue: has a memory address; rvalue: temporary value without address.

  16. Explain operator precedence with an example. Defines the order of operations; e.g., 3 + 4 * 5 equals 23, not 35.

  17. What is the ternary operator in C++ and how is it used? condition ? expr1 : expr2; — returns expr1 if true, else expr2.

  18. Differentiate between ++i and i++. ++i increments before use; i++ increments after use.

  19. What is the purpose of the sizeof operator? Returns the memory size of a data type or object.

  20. What is the meaning of volatile keyword? Indicates a variable can be changed unexpectedly, preventing compiler optimizations.

  21. How does const differ when applied to pointers vs. values? const int* p: value pointed to is constant; int* const p: pointer itself is constant.

  22. What is a reference variable? An alias for another variable, allowing indirect access.

  23. How does a C++ program get converted from source code to executable? Preprocessing → Compilation → Linking → Executable generation.

  24. Explain the purpose of header files in C++. They declare functions, classes, and macros for reuse across files.

  25. What is the difference between #define and const? #define is a preprocessor macro; const is a typed constant with scope and type safety.

Section B — Control Flow & Functions (Q26–Q50)

  1. What are the different types of loops in C++? for, while, and do-while loops.

  2. How does a for loop differ from a while loop? for has initialization, condition, and increment in one line; while only checks the condition.

  3. What is a do-while loop and when is it preferred? Executes the loop body at least once; preferred when at least one execution is needed.

  4. Explain the use of break and continue statements. break exits the loop; continue skips the current iteration.

  5. What is a switch statement and when is it used? Selects execution path based on discrete values; used for multi-way branching.

  6. How does a goto statement affect code readability? It can make code harder to follow and maintain; generally discouraged.

  7. What is the difference between return 0; and return 1; in main()? return 0; signals success; return 1; signals an error or abnormal termination.

  8. How do you define a function in C++? Specify return type, name, parameters, and function body: int add(int a, int b) { return a + b; }.

  9. What is function overloading? Defining multiple functions with the same name but different parameter lists.

  10. Explain the concept of default function arguments. Parameters that take a default value if no argument is provided during a call.

  11. What is an inline function? A function suggested to the compiler to expand at the call site to reduce function call overhead.

  12. What is recursion? Give an example. A function calling itself; e.g., factorial: int fact(int n){ return n<=1?1:n*fact(n-1); }.

  13. What is the difference between pass-by-value and pass-by-reference? Value: copies the argument; Reference: uses the original variable.

  14. Explain what a function prototype is. Declaration of a function before its definition, specifying return type and parameters.

  15. What are static functions and where are they used? Functions limited to the file scope; used for encapsulation.

  16. What are lambda functions in C++? Anonymous functions defined inline with [capture](parameters){body} syntax.

  17. What does the constexpr keyword mean? Indicates a value or function can be evaluated at compile-time.

  18. What is the purpose of the return statement? Ends function execution and optionally provides a value to the caller.

  19. What are pure functions? Functions that produce the same output for the same input and have no side effects.

  20. How can you prevent a function from being inlined? Use the noinline attribute or avoid the inline keyword.

  21. What is the difference between a function and a method? Method is a function that belongs to a class/object; function may be standalone.

  22. What are function pointers in C++? Variables that store the address of a function for dynamic calling.

  23. What is the use of auto return type deduction in functions? Allows the compiler to deduce the return type automatically.

  24. Can we overload the main() function? Why or why not? No; main() is the entry point and its signature must be unique.

  25. How are function templates used in C++? To create generic functions that work with any data type.

Section C — Arrays, Pointers & References (Q51–Q75)

  1. What is an array in C++? A collection of elements of the same type stored in contiguous memory.

  2. How do arrays differ from vectors? Arrays have fixed size; vectors are dynamic and can grow or shrink.

  3. What is the default value of an uninitialized array? Indeterminate (garbage) for local arrays; zero-initialized for global/static arrays.

  4. What is a pointer? A variable that stores the memory address of another variable.

  5. What is the difference between a pointer and a reference? Pointer can be null and reassigned; reference must refer to an object and cannot be reseated.

  6. What happens when you dereference a null pointer? It causes undefined behavior, often a runtime crash.

  7. How can you allocate and deallocate dynamic memory in C++? Use new to allocate and delete to deallocate (or new[]/delete[] for arrays).

  8. What is a dangling pointer? A pointer that refers to memory that has been deallocated.

  9. Explain pointer arithmetic. Operations like ptr + n move the pointer by n elements of its type.

  10. What does the nullptr keyword represent? A null pointer constant that safely represents “no object.”

  11. How can you return a pointer from a function safely? Return pointers to dynamically allocated memory or objects with lifetime outside the function.

  12. What is the relationship between arrays and pointers in C++? Array name decays to a pointer to its first element.

  13. How do you find the size of an array using sizeof? sizeof(array)/sizeof(array[0]).

  14. What is a double pointer? A pointer that points to another pointer.

  15. How do you pass an array to a function? Pass as a pointer (int arr[] or int* arr) along with its size.

  16. What is the difference between char* and std::string? char* is a C-style string (raw pointer), std::string is a safer, dynamic C++ string class.

  17. How do you prevent buffer overflows with C-style strings? Use bounds checking, strncpy, or prefer std::string.

  18. How can you use std::array in modern C++? std::array<int, 5> arr; — fixed-size array with STL interface.

  19. What is pointer decay? When an array automatically converts to a pointer to its first element.

  20. How does const affect pointers (const int*, int* const, etc.)? const int* p → value can’t change, pointer can; int* const p → pointer can’t change, value can.

  21. What are wild pointers and how can they be avoided? Uninitialized pointers pointing to random memory; initialize pointers or set to nullptr.

  22. What is memory alignment and padding? Adjusting memory addresses for performance; padding fills unused space in structs.

  23. What is a reference to a pointer? A reference variable that refers to a pointer, allowing modification of the pointer itself.

  24. What happens if you delete a pointer twice? Undefined behavior, often crashes or memory corruption.

  25. How can std::unique_ptr replace raw pointers? It provides automatic, exclusive ownership with automatic deletion when out of scope.

Section D — Preprocessor & Compilation (Q76–Q90)

  1. What is the role of the C++ preprocessor? It processes directives like #include, #define, and conditionals before compilation.

  2. What are macros and how do they work? Macros are text substitutions performed by the preprocessor.

  3. What are include guards and why are they needed? They prevent multiple inclusion of the same header file using #ifndef/#define/#endif.

  4. What is #pragma once used for? A non-standard but widely supported way to prevent multiple inclusion of a header.

  5. What is conditional compilation? Compiling specific parts of code based on conditions using directives like #if and #ifdef.

  6. How do you define macros with arguments? Using syntax like #define SQR(x) ((x)*(x)).

  7. What are the drawbacks of macros compared to inline functions? No type checking, harder debugging, and unexpected expansions.

  8. How can macros lead to subtle bugs? Because they perform raw text substitution without respecting operator precedence.

  9. What does #undef do? It removes a previously defined macro.

  10. What are predefined macros like __FILE__ and __LINE__? Built-in macros giving file name and line number during compilation.

  11. How can macros be used for debugging? By printing diagnostic info, e.g., file and line using predefined macros.

  12. What is the difference between #error and #warning? #error stops compilation; #warning emits a warning but continues.

  13. How do preprocessors handle nested includes? They expand them recursively until all included files are processed.

  14. How do you disable a section of code during compilation using preprocessor directives? Wrap it in #if 0 … #endif.

  15. What happens during each compilation stage (preprocessing, compiling, linking)? Preprocessing expands directives → compiling converts source to object code → linking combines objects into an executable.

Section E — Input/Output Streams (Q91–Q100)

  1. What is the purpose of the <iostream> header? It provides input/output stream classes like cin, cout, and cerr.

  2. What are cin, cout, cerr, and clog? cin reads input, cout prints normal output, cerr prints errors unbuffered, clog prints errors buffered.

  3. What is the difference between cout and printf? cout is type-safe and object-oriented; printf is C-style and format-string based.

  4. How do you take input from the user in C++? Using cin >> variable;.

  5. How can you format output using manipulators (setw, setprecision, etc.)? Include <iomanip> and apply them to streams, e.g., cout << setw(5) << x;.

  6. What are stream states (good, fail, bad, eof)? They indicate success, recoverable error, serious error, and end-of-file respectively.

  7. How do you clear the error state of a stream? Use cin.clear(); plus cin.ignore(); if needed.

  8. What is the difference between buffered and unbuffered output? Buffered waits before writing; unbuffered writes immediately.

  9. How can you redirect output from console to a file? Use file streams: ofstream file("out.txt"); file << data;.

  10. How can you synchronize C++ streams with C’s stdio library? Call std::ios::sync_with_stdio(true);.

Batch 2: Object-Oriented Programming in C++ (Q101–Q200)

Section A — Classes, Objects, and Encapsulation (Q101–Q125)

  1. What is a class in C++? A class is a blueprint that describes what an object can have and do.

  2. How is a class different from a structure in C++? A class defaults to private members, while a structure defaults to public ones.

  3. What is an object? An object is a real-use version created from a class blueprint.

  4. How do you create and use objects in C++? You make an object by declaring it from a class and then use its functions or variables with dot notation.

  5. What is the difference between a class definition and a class declaration? A definition describes everything inside the class, while a declaration simply tells the compiler that it exists.

  6. What are access specifiers? They are labels that control who can use or see class members.

  7. Explain the difference between public, private, and protected access. Public is for everyone, private is only for the class, and protected is for the class and its children.

  8. What is encapsulation, and why is it important? Encapsulation hides details so users only interact with safe, clean parts of a class.

  9. What does the this pointer represent? It points to the object that is currently running the function.

  10. What is a constructor? A constructor sets up an object when it is created.

  11. How does a default constructor differ from a parameterized constructor? A default constructor takes no values, while a parameterized one takes input.

  12. What is a copy constructor? It creates a new object by copying another object.

  13. What happens if you don’t define a constructor in a class? C++ makes a simple default one for you.

  14. What is a destructor? It’s a special function that cleans up when an object is done.

  15. When is a destructor automatically called? It gets called when an object goes out of scope or is deleted.

  16. Can constructors and destructors be virtual? Constructors cannot be virtual, but destructors can.

  17. What is constructor delegation? It means one constructor calls another to reuse setup work.

  18. What is the difference between initialization and assignment? Initialization sets a value at creation, while assignment changes it later.

  19. What is a member initializer list and why is it preferred? It sets values before the body runs and works faster and cleaner.

  20. Can we overload constructors? Yes, you can make multiple constructors with different inputs.

  21. How do you make an object constant? You declare it with the const keyword.

  22. What is the use of mutable members? They allow changing a variable even inside a const object.

  23. What is const correctness in member functions? It means marking functions const when they don’t change the object.

  24. Can you call a non-const function from a const object? No, a const object can only call const functions.

  25. How can you prevent a class from being instantiated? You make its constructor private or declare at least one pure virtual function.

Section B — Static Members and Friend Functions (Q126–Q150)

  1. What are static data members? They are variables shared by all objects of a class.

  2. What is the purpose of static member functions? They work with static data without needing an object.

  3. How do static members differ from regular class members? Static members belong to the class, not each object.

  4. How are static data members initialized? They are defined and assigned outside the class.

  5. What are the advantages of static members? They save memory and allow shared, consistent values.

  6. Can static member functions access non-static members? No, because they don’t have an object to refer to.

  7. What happens when multiple objects share a static data member? They all see and use the same value.

  8. What is a friend function? It’s an outside function allowed to access private data.

  9. What is a friend class? A class given special access to another class’s private parts.

  10. How does a friend function differ from a member function? A friend is outside the class but still trusted; a member is inside.

  11. Can friendship be inherited? No, child classes don’t automatically get that trust.

  12. Can a function be a friend of multiple classes? Yes, one function can be trusted by many classes.

  13. Is friendship mutual? No, both sides must declare it separately.

  14. Is friendship transitive? No, trust doesn’t pass automatically through classes.

  15. Why might you use a friend function instead of getters/setters? It can access private data cleanly without many small functions.

  16. How can friend functions help with operator overloading? They let operators work with private data from both objects.

  17. Can a friend function be virtual? No, because it isn’t part of the class.

  18. Can templates be friends? Yes, you can make a template or its instance a friend.

  19. What are the security implications of using friend functions? They weaken encapsulation by exposing private data.

  20. How can you limit access to private data without using friends? Use public functions or interfaces that expose only what’s needed.

  21. What is a static object? It’s an object that stays alive for the entire program or scope.

  22. How are static objects destroyed? They are destroyed automatically at program end or when their scope ends.

  23. What is the lifetime of a global static object? From program start until program termination.

  24. What is a singleton pattern and how is it implemented? It’s a design where only one object exists, usually via a private constructor and a static getter.

  25. What are the drawbacks of singletons? They create hidden dependencies and make testing harder.

Section C — Inheritance (Q151–Q175)

  1. What is inheritance in C++? It lets one class reuse and extend another class’s features.

  2. Why is inheritance useful in object-oriented programming? It reduces repetition by sharing common code.

  3. What is the difference between public, private, and protected inheritance? Public keeps access similar, private hides everything, protected limits outside use.

  4. Can a class inherit from multiple base classes? Yes, C++ allows multiple inheritance.

  5. What are base and derived classes? The base gives features; the derived receives and extends them.

  6. What is the order of constructor and destructor calls in inheritance? Constructors run base-to-derived; destructors run derived-to-base.

  7. What happens when both base and derived classes have a function with the same name? The derived version hides the base one.

  8. How do you explicitly call a base class method in a derived class? Use Base::functionName().

  9. What is function overriding? A derived class replaces a virtual function with its own version.

  10. What is slicing in C++? It’s when a derived object loses its extra parts when stored as a base.

  11. What is a virtual function? A function meant to be overridden and called based on actual object type.

  12. What happens if a derived class object is assigned to a base class pointer? The pointer sees only the base parts unless functions are virtual.

  13. What is a vtable? A hidden table that stores addresses of virtual functions.

  14. How is dynamic dispatch achieved in C++? Through the vtable using virtual functions.

  15. What is the role of the override keyword? It confirms you are correctly overriding a virtual function.

  16. What does final mean in the context of classes and methods? It stops further inheritance or overriding.

  17. What are pure virtual functions? Virtual functions with no body, forcing derived classes to implement them.

  18. What is an abstract base class? A class with at least one pure virtual function that cannot be instantiated.

  19. Can a constructor be virtual? Why or why not? No, because objects don’t exist yet to dispatch through a vtable.

  20. Can a destructor be virtual? Why is it important? Yes, to ensure correct cleanup when deleting through a base pointer.

  21. What is multiple inheritance? A class inheriting from more than one base class.

  22. What is the “diamond problem” in C++? It’s when a class inherits from two classes that share a common base, causing duplication.

  23. How is the diamond problem resolved in modern C++? By using virtual inheritance.

  24. What are virtual base classes? Base classes shared once across a hierarchy to avoid duplication.

  25. Can you inherit constructors in C++? Yes, using using Base::Base;.

Section D — Polymorphism (Q176–Q190)

  1. Define polymorphism. It lets one interface act differently based on the actual object type.

  2. What is the difference between compile-time and runtime polymorphism? Compile-time is decided early; runtime is decided while the program runs.

  3. What mechanisms in C++ provide compile-time polymorphism? Function overloading, operator overloading, and templates.

  4. What mechanisms provide runtime polymorphism? Virtual functions and inheritance.

  5. What is operator overloading? It gives operators custom meaning for your own types.

  6. Which operators cannot be overloaded? ::, ., .*, ?:, and sizeof.

  7. How do you overload the << and >> operators? You write friend functions that take streams and your object.

  8. What is function hiding in C++? A derived function with the same name blocks the base version.

  9. How can you prevent function hiding? Use using Base::functionName;.

  10. What is object slicing and why does it occur? It happens when storing a derived object as a base value, losing its extra parts.

  11. How can slicing be avoided when using polymorphism? Use pointers or references instead of value copies.

  12. What are covariant return types? They allow overridden functions to return a more specific derived type.

  13. What is the significance of virtual destructors in polymorphic base classes? They ensure deletion through a base pointer cleans up the full object.

  14. What is RTTI (Run-Time Type Information)? It’s metadata that lets you check an object’s real type at runtime.

  15. What are typeid and dynamic_cast used for? typeid reports type info; dynamic_cast safely converts pointers or references.

Section E — Object Lifetime, RAII, and Special Member Functions (Q191–Q200)

  1. What is RAII (Resource Acquisition Is Initialization)? It’s a method where objects grab resources in constructors and release them in destructors.

  2. Why is RAII considered a safe programming paradigm? It guarantees cleanup even if something goes wrong.

  3. What are the Rule of Three, Rule of Five, and Rule of Zero? They guide how many special functions you must define based on resource ownership.

  4. What are copy constructors and copy assignment operators? They create or assign an object by copying another one’s data.

  5. What are move constructors and move assignment operators? They transfer resources from one object to another without copying.

  6. What is the difference between shallow copy and deep copy? Shallow copies pointers; deep copy duplicates the actual data.

  7. How can you prevent copying of an object? Delete the copy constructor and copy assignment operator.

  8. What happens if you don’t define a copy constructor? C++ auto-generates one that copies members one by one.

  9. How can you use = delete to prevent specific operations? Mark the unwanted function with = delete so it cannot be called.

  10. What are best practices for managing resources in class design? Use RAII, avoid raw pointers, and let smart objects manage cleanup.

Batch 3: STL Fundamentals & Containers (Q201–Q300)

Section A — STL Basics (Q201–Q225)

  1. What is the Standard Template Library (STL) in C++? → A collection of generic classes and functions for data structures and algorithms.

  2. What are the main components of the STL? → Containers, iterators, algorithms, and functors.

  3. Why was STL introduced in C++? → To provide reusable, efficient, and generic implementations of common structures and algorithms.

  4. What are templates in C++? → Blueprints that allow writing code independent of data types.

  5. What is the difference between function templates and class templates? → Function templates generalise functions, while class templates generalise classes.

  6. What is the purpose of template specialization? → To define custom behaviour for specific template types.

  7. What is a container in STL? → A data structure that stores and organizes collections of elements.

  8. What is the difference between a sequential and an associative container? → Sequential stores elements linearly; associative stores elements by key-based lookup.

  9. What are iterator categories in STL? → Input, output, forward, bidirectional, and random-access types defining iterator capabilities.

  10. Explain input, output, forward, bidirectional, and random-access iterators. → They range from simple read/write iteration to full movement in both directions with index-like jumps.

  11. What is the difference between an iterator and a pointer? → Iterators behave like abstracted pointers but work across different container types.

  12. How do you obtain an iterator for an STL container? → By calling methods like begin() and end().

  13. What is begin() and end() in STL containers? → begin() points to the first element; end() points past the last.

  14. What is the difference between cbegin() and begin()? → cbegin() returns a read-only iterator; begin() may allow modification.

  15. How do rbegin() and rend() work? → They iterate the container in reverse from last to before first.

  16. What is iterator invalidation? → When an iterator becomes unusable after container changes.

  17. What operations cause iterator invalidation? → Typically insertions, deletions, or reallocation in containers.

  18. How do const_iterator and iterator differ? → const_iterator forbids modification of elements; iterator allows it.

  19. What is a reverse iterator? → An iterator that moves backward through a container.

  20. Can iterators be compared like pointers? → Yes, but only when they belong to the same container and category supports it.

  21. What is std::distance() used for? → To compute how far two iterators are apart.

  22. What is std::advance() used for? → To move an iterator forward or backward by a given number of steps.

  23. How can you check if an STL container is empty? → By calling its empty() method.

  24. What is the time complexity of size() for different containers? → Constant-time for most containers but linear for forward_list.

  25. What is the role of std::initializer_list in STL containers? → It enables brace-initialisation of containers with predefined values.

Section B — Sequence Containers (Q226–Q250)

  1. What are sequence containers? → Containers that store elements in a linear, ordered sequence.

  2. Name the main sequence containers in STL. → vector, deque, list, forward_list, and array.

  3. What are the advantages of using std::vector? → Dynamic growth, cache-friendly access, and fast end insertions.

  4. What is the difference between std::vector and a C-style array? → Vectors resize dynamically; C arrays have fixed size.

  5. How does std::vector handle memory allocation? → It allocates extra space and grows geometrically when needed.

  6. What does vector::capacity() represent? → The amount of allocated space available before growth occurs.

  7. How do you shrink the capacity of a vector? → Use shrink_to_fit() (non-binding request).

  8. What happens when you call reserve() on a vector? → It pre-allocates at least the requested capacity.

  9. What happens when you exceed a vector’s capacity? → It reallocates, moves elements, and increases capacity.

  10. What is the complexity of inserting an element at the end of a vector? → Amortised constant time.

  11. What is the complexity of inserting an element at the beginning of a vector? → Linear time.

  12. What are emplace functions (emplace_back, emplace_front)? → Methods that construct elements directly in place.

  13. What is the difference between push_back and emplace_back? → push_back inserts an existing object; emplace_back builds it on site.

  14. How do you remove an element from a vector? → Use erase() or the erase-remove idiom.

  15. What does the “erase-remove idiom” mean? → Combining remove() and erase() to delete matching elements.

  16. How do you swap two vectors efficiently? → Use std::swap() or vector::swap() which swaps internal pointers.

  17. What is std::array and how does it differ from C arrays? → A fixed-size wrapper with safer and richer API than C arrays.

  18. What is the advantage of using std::deque? → Fast insertions and deletions at both ends.

  19. What is the difference between std::list and std::forward_list? → list is doubly linked; forward_list is singly linked.

  20. How does std::list store its elements internally? → As nodes linked in a doubly linked chain.

  21. Can std::vector be used as a stack? → Yes, by using push_back and pop_back.

  22. How do you iterate through a std::list? → With iterators from begin() to end().

  23. When should you prefer std::deque over std::vector? → When frequent front insertions or deletions are needed.

  24. Why doesn’t std::array support dynamic resizing? → Because its size is fixed at compile time.

  25. What are the performance characteristics of std::vector, std::list, and std::deque? → Vector is fastest for contiguous access, list excels at mid insertions, deque is strong at both-end operations.

Section C — Associative Containers (Q251–Q275)

  1. What are associative containers? → Containers that store elements in sorted or hashed structures using keys.

  2. What are the main associative containers in STL? → set, multiset, map, and multimap.

  3. How is data organized in associative containers? → Typically in balanced binary search trees.

  4. What is the difference between std::set and std::multiset? → set stores unique keys; multiset allows duplicates.

  5. What is the difference between std::map and std::multimap? → map has unique keys; multimap permits repeated keys.

  6. What are the key and value types in std::map? → Keys and mapped values stored as std::pair<const Key, T>.

  7. How does std::map maintain sorted order? → By using a balanced tree (usually a red-black tree).

  8. What is the default comparison function used by std::set and std::map? → std::less.

  9. How can you use custom comparators in std::map? → By providing a comparator type as a template argument.

  10. What is the time complexity for insert, erase, and find in std::map? → Logarithmic time.

  11. What happens if you insert a duplicate key in std::map? → The insertion is ignored.

  12. What is the difference between operator[] and at() in std::map? → operator[] inserts a default value if missing; at() throws on missing keys.

  13. What is lower_bound() and upper_bound()? → They give the first not-less-than and first greater-than positions.

  14. What is equal_range() used for? → To return both bounds for a key at once.

  15. What are the typical use cases for std::set? → Unique element storage, fast lookup, and sorted retrieval.
