Batch 1: Python Basics & Core Programming (Q1–Q100)

Core Syntax & Variables

  1. What is Python, and how is it different from other programming languages? → Python is a beginner-friendly language that focuses on readability and simplicity compared to many others.

  2. How do you declare a variable in Python? → Just assign a value like x = 5—no type declaration needed.

  3. What are Python’s standard data types? → Numbers, strings, lists, tuples, dictionaries, sets, and booleans.

  4. What is the difference between mutable and immutable types? → Mutable types can change their contents, immutable ones cannot.

  5. Explain the difference between is and ==. → == checks value equality, while is checks if two things are the exact same object.

  6. What are Python’s basic arithmetic operators? → +, -, *, /, //, %, and **.

  7. How does Python handle operator precedence? → It follows a fixed priority order (like maths) to decide which operation runs first.

  8. What is the difference between // and /? → / gives a float result, while // gives a floor (rounded-down) result.

  9. How do you swap two variables without a temporary variable? → Use a, b = b, a.

  10. Explain the difference between str(), repr(), and format(). → str() makes things user-friendly, repr() makes them unambiguous for developers, and format() lets you style the output.

Control Flow

  1. Explain the syntax of an if-elif-else statement. → It checks conditions in order using if, then elif if needed, and else when nothing else matches.

  2. What is the difference between while and for loops? → while repeats until a condition changes, while for repeats over items in a sequence.

  3. How do break, continue, and pass statements work? → break stops the loop, continue skips to the next round, and pass does nothing at all.

  4. How do you loop over a dictionary? → You loop using for key, value in dict.items().

  5. How do you loop over a list with indexes? → Use for i in range(len(my_list)).

  6. Explain Python’s enumerate() function. → It gives you both the index and the value while looping.

  7. What is the purpose of the else clause in loops? → It runs only if the loop finishes normally without a break.

  8. How do nested loops work in Python? → One loop runs inside another so the inner loop repeats fully for each outer loop step.

  9. Explain the difference between range() and xrange() (Python 2 vs 3). → range() makes a list in Python 2 but works like xrange() in Python 3, which generates values on the fly.

  10. How would you iterate over two lists simultaneously? → Use for a, b in zip(list1, list2).

Functions

  1. How do you define a function in Python? → You create one with def name(): like a tiny machine that runs when called.

  2. Explain positional vs keyword arguments. → Positional go by order, keyword go by name—like calling someone by seat number vs calling them by name.

  3. What are default arguments in Python functions? → They’re backup values the function uses if you don’t give your own.

  4. How do you define a function with variable arguments (*args, **kwargs)? → Use *args for extra unnamed stuff and **kwargs for extra named stuff like a magical backpack of inputs.

  5. What is a lambda function? → A teeny-tiny one-line function used when you’re in a hurry.

  6. How do you return multiple values from a function? → Just separate them with commas and they come back as a tuple.

  7. What is recursion, and give an example? → It’s when a function calls itself, like a mirror reflecting another mirror.

  8. Explain the difference between a function and a method. → A method is just a function that lives inside an object and behaves politely about it.

  9. What are docstrings, and how are they used? → They’re little notes inside triple quotes that explain what your function does.

  10. How do you import a function from another module? → Use from module import function like borrowing a tool from a neighbor.

Data Structures: Lists

  1. How do you create a list in Python? → Put values inside brackets like [1, 2, 3].

  2. How do you access elements in a list? → Use indexes like my_list[0].

  3. How do you slice a list? → Use my_list[start:end] to grab a piece of it.

  4. How do you add an element to a list? → Use append() or insert() depending on where you want it.

  5. How do you remove an element from a list? → Use remove(), pop(), or del depending on your mood.

  6. How do you sort a list? → Use sort() for in-place or sorted() for a fresh sorted copy.

  7. How do you reverse a list? → Use reverse() or slice it like my_list[::-1].

  8. What are list comprehensions, and give an example? → They’re quick list-makers like [x*2 for x in nums].

  9. How do you check if an element exists in a list? → Use if item in my_list.

  10. How do you copy a list (shallow vs deep copy)? → Shallow uses list.copy(); deep uses copy.deepcopy() for fully separate copies.

Data Structures: Tuples

  1. What is a tuple in Python? → It’s an ordered collection that you can’t change once created.

  2. How is a tuple different from a list? → A list can change, a tuple stays frozen.

  3. How do you access elements in a tuple? → Use indexing like t[0].

  4. Can you modify a tuple? Explain. → Nope, it’s immutable so its contents are locked in.

  5. What are tuple packing and unpacking? → Packing bundles values into a tuple, unpacking splits them back out into variables.

  6. How can tuples be used as dictionary keys? → Because tuples never change, they work as stable keys.

  7. Explain nested tuples with an example. → A tuple inside another like (1, (2, 3)).

  8. How do you iterate over a tuple? → Use a simple for item in tuple: loop.

  9. What is the purpose of the namedtuple in collections? → It gives tuples names for their fields so they behave like lightweight objects.

  10. How do you convert a tuple to a list and vice versa? → Use list() to turn a tuple into a list and tuple() to turn a list into a tuple.

Data Structures: Dictionaries

  1. How do you create a dictionary? → Use curly braces like {"a": 1, "b": 2}.

  2. How do you access values in a dictionary? → Use the key like my_dict["a"].

  3. How do you add or update dictionary elements? → Assign with my_dict[key] = value.

  4. How do you remove elements from a dictionary? → Use pop(), del, or popitem().

  5. How do you iterate over keys, values, and items? → Use dict.keys(), dict.values(), and dict.items().

  6. What is the purpose of defaultdict? → It gives automatic default values so you don’t get key errors.

  7. How do you merge two dictionaries? → Use {**d1, **d2} or d1.update(d2).

  8. How do you sort a dictionary by keys or values? → Use sorted() on dict.items() with a key function.

  9. Explain dictionary comprehension. → It’s a quick way to build dictionaries like {x: x*2 for x in nums}.

  10. Can dictionary keys be mutable? Explain. → No, keys must stay the same forever, so only immutable types qualify.

Data Structures: Sets

  1. How do you create a set in Python? → Use curly braces like {1, 2, 3} or set().

  2. What are the main properties of sets? → They’re unordered, unique, and super fast for membership checks.

  3. How do you add or remove elements in a set? → Use add() to include and remove() or discard() to take away.

  4. What is the difference between remove() and discard()? → remove() complains if the item’s missing, discard() stays chill.

  5. How do you perform union, intersection, and difference on sets? → Use |, &, and - or their method versions.

  6. How do you check if a set is a subset or superset of another set? → Use <, <=, >, >= or the .issubset() and .issuperset() methods.

  7. What is a frozenset? → A set that can’t be changed, like a set in winter mode.

  8. How do you iterate over a set? → Use a simple for item in my_set: loop.

  9. Can sets contain duplicate elements? → No, they automatically toss out repeats.

  10. Explain practical use cases of sets. → They’re perfect for removing duplicates, fast lookups, and comparing groups of things.

Exception Handling

  1. What is exception handling in Python? → It’s the way Python deals with errors without crashing your program.

  2. Explain try, except, finally, and else blocks. → try tests code, except handles errors, else runs if no error happens, and finally always runs at the end.

  3. How do you raise an exception in Python? → Use raise SomeError("message").

  4. What are some common Python exceptions? → ValueError, TypeError, KeyError, IndexError, ZeroDivisionError.

  5. How do you create a custom exception class? → Make a class that inherits from Exception.

  6. What is the difference between Exception and BaseException? → BaseException is the root of all errors, and Exception is the normal branch most errors use.

  7. How do you catch multiple exceptions in a single block? → Put them in a tuple like except (TypeError, ValueError):.

  8. What is the use of with statement for exception handling? → It safely manages resources so they close even if errors happen.

  9. Explain the difference between syntax errors and runtime errors. → Syntax errors break the code before it runs; runtime errors happen while running.

  10. How do you log exceptions for debugging? → Use the logging module and logging.exception() to record error details.

File I/O

  1. How do you open and close a file in Python? → Use open() to open and close() to shut it.

  2. What is the difference between text and binary files? → Text stores characters, binary stores raw bytes.

  3. How do you read a file line by line? → Loop over the file object directly.

  4. How do you write to a file? → Open it in write mode and use write().

  5. What is the difference between read(), readline(), and readlines()? → read() gets everything, readline() gets one line, readlines() gets all lines in a list.

  6. How do you append to a file? → Open it in 'a' mode and use write().

  7. What are file modes in Python (r, w, a, b)? → r reads, w overwrites, a adds, b switches to binary.

  8. How do you use a context manager (with) for file handling? → Wrap the file in with so it closes itself automatically.

  9. How do you check if a file exists before opening it? → Use os.path.exists().

  10. How do you handle file exceptions safely? → Wrap file operations in try-except blocks.

Modules, Packages & Virtual Environments

  1. What is a module in Python? → It’s just a file full of Python code you can reuse.

  2. How do you import a module? → Use import module_name.

  3. Explain the difference between import module and from module import function. → One brings the whole toolbox, the other grabs just one tool.

  4. How do you create a package in Python? → Put modules in a folder with an __init__.py file.

  8. How do you create a virtual environment? → Run python -m venv envname.

  9. Why are virtual environments important? → They keep your project’s packages nicely separated from others.

  10. How do you activate and deactivate a virtual environment? → Activate with source env/bin/activate (or Scripts\activate on Windows) and deactivate with deactivate.

Batch 2: Advanced Python Programming (Q101–Q200)

Iterators & Generators

  1. What is an iterator in Python? → It’s something you can move through one item at a time.

  2. How does the iter() function work? → It turns an iterable into an iterator.

  3. Explain the next() function. → It gives you the next item from an iterator.

  4. How do you create a custom iterator class? → Define __iter__() and __next__() inside a class.

  5. What is a generator in Python? → It’s a special function that makes an iterator automatically.

  6. How does yield differ from return? → yield pauses the function, return stops it for good.

  7. What are generator expressions? → They’re tiny generators written like (x*2 for x in nums).

  8. How do generators help with memory efficiency? → They produce items only when needed instead of storing everything.

  9. Explain the difference between an iterator and an iterable. → An iterable can give you an iterator; an iterator actually moves through items.

  10. How do you chain generators for complex pipelines? → You stack them by feeding one generator’s output into the next.

Comprehensions

  1. Explain list comprehensions with an example. → They build lists fast, like [x*x for x in nums].

  2. How do dictionary comprehensions work? → They create key–value pairs quickly like {x: x*x for x in nums}.

  3. Explain set comprehensions. → They make sets using a similar style like {x*x for x in nums}.

  4. How do you use nested comprehensions? → Put one inside another like [a+b for a in A for b in B].

  5. How can you add conditions to comprehensions? → Add an if like [x for x in nums if x%2==0].

  6. What is the difference between a comprehension and a generator expression? → One builds the whole structure; the other makes items on demand.

  7. How do comprehensions improve code readability? → They shrink big loops into neat one-liners.

  8. Can comprehensions replace loops entirely? → Not always, but they handle many loop scenarios nicely.

  9. Explain the performance benefits of comprehensions. → They run faster because they’re optimized inside Python.

  10. How do you handle exceptions in comprehensions? → Wrap the whole comprehension in a try-except since you can’t catch inside it cleanly.

Object-Oriented Programming (OOP)

  1. What is a class in Python? → It’s a blueprint for creating objects.

  2. What is an object? → It’s a thing made from a class with its own data and abilities.

  3. Explain the difference between instance, class, and static methods. → Instance methods use self, class methods use cls, and static methods use neither.

  4. What is inheritance? Give an example. → It lets one class get features from another, like Dog(Animal).

  5. What is multiple inheritance, and how does Python handle it? → A class can inherit from many parents, and Python uses MRO to decide who gets priority.

  6. What is polymorphism in Python? → Different objects can use the same method name but behave differently.

  7. Explain encapsulation and how it is implemented. → It hides internal details using naming conventions like _name.

  8. What are private, protected, and public attributes in Python? → Public for everyone, protected with one underscore, private with two underscores.

  9. What is method overriding? → A child class replaces a parent class’s method with its own version.

  10. Explain method overloading in Python. → Python fakes it using default or variable arguments since it doesn’t support it directly.

  1. What are magic methods in Python? → Special methods with double underscores that let objects behave in magical ways.

  5. Explain __len__, __iter__, and __next__. → They let objects act like sequences you can measure and loop through.

  6. How do __enter__ and __exit__ relate to context managers? → They power the with statement by setting up and cleaning up.

  7. Explain operator overloading with __add__ or __mul__. → These methods let your objects respond to + and * in custom ways.

  8. What is __dict__ used for? → It stores an object’s attributes in a handy dictionary.

  9. How do you implement custom comparison operators? → Define methods like __lt__, __gt__, __eq__, and friends.

  10. How can magic methods enhance code readability? → They make objects act naturally so your code feels smooth and intuitive.

Properties, Descriptors & Metaclasses

  1. What is the property() function used for? → It turns methods into managed attributes with built-in getters and setters.

  2. How do you define getter, setter, and deleter in Python? → Use @property, @attr.setter, and @attr.deleter decorators.

  4. How do you implement custom descriptors? → Define a class with __get__, __set__, or __delete__.

  5. What are the use cases for descriptors? → They’re great for validation, computed attributes, and shared behavior.

  6. What is a metaclass in Python? → It’s a class that creates other classes.

  7. How do you create a custom metaclass? → Inherit from type and override methods like __new__ or __init__.

  8. Explain the role of type() in metaclasses. → type() is the default metaclass that builds classes.

  9. How do metaclasses control class creation? → They intercept the class-building process and can modify it.

  10. Give a practical example of using metaclasses. → They can auto-add logging, enforce naming rules, or register classes automatically.

Functional Programming

  1. What is functional programming? → It’s a style where you build programs using functions without changing data.

  2. Explain the use of map() with an example. → map(f, items) applies a function to each item, like map(str.upper, words).

  3. How does filter() work in Python? → It keeps only the items that pass a test function.

  4. Explain reduce() and where it is used. → It combines items into one value, like adding everything up.

  5. What is functools in Python? → A module full of handy functional tools.

  6. Explain partial() from functools. → It pre-fills part of a function’s arguments to make a new function.

  7. How do higher-order functions work in Python? → They accept functions as inputs or return them as outputs.

  8. What are pure functions? → Functions that don’t change anything and always give the same output for the same input.

  9. Explain immutability in functional programming. → It means data never changes, so you make new copies instead.

  10. How does Python support first-class functions? → Functions can be stored, passed, returned, and treated like any other value.

Decorators

  1. What is a decorator in Python? → It’s a function that adds extra superpowers to another function.

  2. How do you create a simple decorator function? → Make a wrapper inside a function and return that wrapper.

  3. Explain the difference between function decorators and class decorators. → One decorates functions, the other decorates entire classes.

  4. How do you use functools.wraps? → Put it on your wrapper so the original function’s name and docs stay intact.

  5. Can decorators accept arguments? → Yep—just wrap another layer around the decorator.

  6. Explain chaining decorators. → Stack them so a function passes through several decorators.

  7. How can decorators improve code reusability? → They let you reuse behavior without rewriting it everywhere.

  8. Give a practical example of a logging decorator. → A decorator that prints function name and arguments before running it.

  9. How do property decorators work? → They turn methods into attribute-like access using @property.

  10. Explain the difference between @staticmethod, @classmethod, and @property. → Static ignores the class, classmethod uses the class, property acts like a managed attribute.

Recursion

  1. What is recursion, and when should it be used? → It’s when a function calls itself, useful for problems that split into smaller versions of themselves.

  2. Explain base case and recursive case. → The base case stops the recursion; the recursive case keeps it going.

  3. How do you prevent infinite recursion? → Always include a base case that actually gets reached.

  4. Compare recursion with iteration. → Recursion uses repeated self-calls, iteration uses loops.

  5. How do you calculate factorial using recursion? → Define n * factorial(n-1) with a base case of 1.

  6. How do you compute Fibonacci numbers using recursion? → Return fib(n-1) + fib(n-2) with base cases 0 and 1.

  7. What is tail recursion? → A recursive call made as the final action in a function.

  8. Does Python optimize tail recursion? → Nope, Python leaves it unoptimized.

  9. How can recursion affect memory (stack overflow)? → Too many nested calls fill up the call stack.

  10. Give a real-world example of recursion. → A folder containing folders inside folders.

Memory Management

  1. How does Python manage memory internally? → It uses private heaps, reference counting, and a garbage collector.

  2. What is reference counting? → A counter tracks how many things point to an object.

  3. How does Python’s garbage collector work? → It cleans up leftover objects, especially those in cycles.

  4. What are circular references, and how are they handled? → Objects that reference each other, handled by the cycle detector.

  5. Explain __del__ method in Python. → It runs when an object is about to be destroyed.

  6. How do weakref objects work? → They let you reference objects without increasing their reference count.

  7. How do you manually trigger garbage collection? → Call gc.collect().

  8. What are memory leaks in Python? → When objects never get freed because something still references them.

  9. How can you optimize memory usage in Python programs? → Use generators, avoid unnecessary copies, and prefer lightweight structures.

  10. Explain the difference between shallow and deep copies. → Shallow copies copy references; deep copies clone everything fully.

Advanced Python Concepts

  1. What is duck typing in Python? → If something behaves like the right type, Python treats it as that type.

  2. Explain EAFP vs LBYL programming styles. → EAFP tries first and handles errors; LBYL checks everything before acting.

  3. What are Python’s built-in functions for introspection? → type(), id(), dir(), hasattr(), getattr(), and friends.

  4. How do you dynamically import a module? → Use importlib.import_module().

  5. How do you check if an object has an attribute? → Use hasattr(obj, "name").

  6. What is the Global Interpreter Lock (GIL)? → A lock that allows only one thread to run Python code at a time.

  7. How does GIL affect multithreading in Python? → CPU-heavy threads can’t run in true parallel.

  8. How do you bypass GIL limitations? → Use multiprocessing or extension modules that release the GIL.

  9. Explain the difference between multithreading and multiprocessing. → Threads share memory; processes run separately for real parallelism.

  10. How can Python’s ctypes or cffi improve performance? → They let you call fast C code directly from Python.
